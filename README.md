# Diamond Willow | MBO campaign dashboard

Front end of the live MBO campaign dashboard, built by Woods.

- Hosted on GitHub Pages and embedded in a password-protected page on diamondwillowadvisory.com.
- Data comes from a Google Apps Script web app (GA4, HubSpot, LinkedIn, responses sheet) that refreshes every hour.
- The data endpoint and access key are passed in the iframe URL (`?api=...&k=...`). This repository holds no keys and no client data.

Files: `index.html`, `styles.css`, `app.js`, `config.js`, `assets/`.
